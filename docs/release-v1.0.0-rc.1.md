# v1.0.0-rc.1

고정일: 2026-09-17. 로컬 stdio 기반 에듀넷 검색 MCP의 Release Candidate다.

## 고정 범위

- `search_edunet` 하나: 검색 조건·카테고리·정렬·페이지 지정, 메타데이터·최대 500자 발췌·API 제공 출처 반환.
- package.json, package-lock.json과 MCP 서버가 알리는 버전을 `1.0.0-rc.1`로 일치시켰다.
- 사용자용 README에 설치, 인증, 클라이언트 연결, 사용 예시 5개, 카테고리와 제한사항을 정리했다.
- MCP 검증과 클라이언트 모델 관측을 분리했다. `npm run check`는 MCP 타입 검사와 오프라인 테스트만 실행한다.
- 보안·오류 점검을 수행하고 기존 회귀 검사를 보강했다. 검색 기능·도구 스키마·검색 안내는 추가 변경하지 않았다.

## 통과 근거

**offline 40/40 PASS · live EDUNET 5/5 PASS · typecheck PASS.** 키 노출, stack trace, 잘못된 입력 후 세션 유지, 장애 오류, 출처 URL 보존 점검도 통과했다. 실행 환경·범위·제한은 [MCP 검증 기록](mcp-validation.md)에 있다.

[Terra·Sonnet 관측](client-compatibility.md)은 별도 참고다. 해당 점수나 과거 평가기의 릴리스 필드는 이 RC의 합격·불합격을 결정하지 않는다.

## 보존 방식

이 작업 폴더는 Git 저장소가 아니므로 Git 태그·커밋을 만들지 않았다. 대신 아래 소스 묶음과 SHA-256 목록으로 기준 파일을 보존한다.

- [RC 소스 ZIP](../releases/edunet-mcp-1.0.0-rc.1.zip)
- [파일별 SHA-256 목록](release-v1.0.0-rc.1.sha256.json)
- ZIP 해시는 `releases/edunet-mcp-1.0.0-rc.1.zip.sha256`에 기록한다.

묶음에는 소스·테스트·실행 스크립트·평가 실행기·문서·잠금 파일·빈 환경변수 예시가 포함된다. 실제 `.env`, 개인 클라이언트 설정, node_modules, dist, 임시 파일, 원시 평가 결과는 포함하지 않는다. 원시 과거 평가 결과는 기존 로컬 위치에 보존한다. ZIP을 새 폴더에 풀고 README대로 `npm ci`와 `npm run build`를 실행한다.

## 이후 변경 원칙

기능 추가를 중단한다. 원격 MCP, 첨부파일 읽기 등 이전 계획의 확장은 보류한다. 실제 사용에서 재현한 문제만 원인·영향·재현 조건을 기록해 수정한다. 키·토큰을 재현 기록에 넣지 않는다.

수정할 때는 관련 회귀 검사와 `npm run check`를 실행하고, API 연동에 영향을 주면 live 검증도 실행한다. 수정된 후보는 `v1.0.0-rc.2`처럼 새 버전과 새 소스 묶음으로 남기며 이 RC의 묶음·해시·당시 검증 결과는 덮어쓰지 않는다.
