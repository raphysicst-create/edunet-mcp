# Codex 클라이언트 연결 확인

확인일: 2026-09-16. Evals와 별도로 실시한 실제 클라이언트 연결 점검이다.

## 등록

이 프로젝트의 `.codex/config.toml`에 `mcp_servers.edunet`을 등록했다. 사용자 전역 설정과 다른 프로젝트 설정은 변경하지 않았다. 프로젝트가 이미 trusted로 등록된 것을 확인했고, `codex mcp list --json`에서 `edunet`이 enabled 상태로 나타났다.

서버 실행 명령은 설치된 Node.js의 절대 경로이며, `--env-file`로 프로젝트 `.env`를 읽고 `dist/index.js`를 실행한다. 설정 파일에 키 값을 복사하지 않았다. 시작 제한은 20초, 도구 호출 제한은 60초이며 `search_edunet`만 노출한다.

[공식 MCP 안내](https://developers.openai.com/codex/mcp)에 따라 프로젝트 설정을 사용했다. 현재 실행 중인 대화에 새 도구가 나타나지 않으면 MCP 설정에서 연결을 다시 시작한 뒤 이 프로젝트의 새 대화를 시작한다. 기존 대화의 도구 목록이 자동으로 갱신되었다고 주장하지 않는다.

## 실제 대화 확인

Codex 데스크톱 앱에 포함된 CLI `0.154.0-alpha.6.2`를 클라이언트로 사용했다. 테스트 프로그램에서 도구 인자를 직접 고정한 것이 아니라, 같은 Codex 대화를 세 차례 이어서 자연어 요청을 전달하고 AI의 실제 MCP 호출 기록을 확인했다. 일반 PATH의 `codex` 명령은 삭제된 npm 패키지를 가리켜 실행되지 않았으므로 앱 내 실행 파일을 사용했다. 전역 CLI 설치는 변경하지 않았다.

| 차례 | 자연어 요청 | 관측한 호출과 결과 |
|---|---|---|
| 1 | 중학교 2학년 과학 광합성 자료를 찾아줘. 한 페이지에 3건만 | 긴 검색어와 축약 검색어가 각각 0건이어서 `광합성`으로 넓혀 다시 검색. 전체 111건 중 3건 반환 |
| 2 | 평가자료만 보여줘. 한 페이지에 3건씩 유지해줘 | `categories=["evl_data"]`, `query=광합성`, `page=1`, `pageSize=3`. 전체 5건 중 3건 반환 |
| 3 | 다음 페이지 보여줘 | 이전 검색어·카테고리·정렬·검색 범위·페이지 크기를 유지하고 `page=2`만 변경. 나머지 2건 반환, 다음 페이지 없음 |

다섯 번의 MCP 호출이 모두 성공했다. 답변의 링크가 실제 도구 결과에 있는 링크인지도 확인했다. 첫 답변은 검색어를 넓힌 사실과 정확한 학년 적합성이 미확인이라는 점을 밝혔으며, 세 답변 모두 원문·첨부파일 미열람을 안내했다. 기록에서 실제 인증키가 노출되지 않았는지 검사했다.

1·3차례는 `gpt-5.6-sol`, 2차례는 재개 시 클라이언트 기본값인 `gpt-6-astra`가 사용되었다. 따라서 이 기록은 모델을 고정한 성능 평가가 아니다. Evals 데이터·실행기·결과는 변경하지 않았다.

## 증거와 범위

`docs/client-connection-data.json`에 사용자 요청, 실제 도구 인자, 반환 결과, 답변과 검사 결과를 기록했다. 원본 CLI JSONL은 Git 제외 경로인 `.scratch/client-turn*.jsonl`에 있다.

확인한 것은 등록된 프로젝트 설정을 읽는 실제 Codex 클라이언트의 MCP 시작·호출·대화 맥락 유지다. 데스크톱 화면을 클릭해 도구 표시를 확인한 것은 아니며, 상세페이지·첨부파일 접근성은 별도의 `docs/link-access-report.md`에서 다룬다.
