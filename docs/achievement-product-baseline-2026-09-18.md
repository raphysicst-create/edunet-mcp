# 성취수준 제품 eval 최초 관측 — 2026-09-18

제품 eval 실행기와 교사 질의 30개를 추가하고 실제 인증 검색을 실행했다. **30개 질의 모두 `not_found_in_official_index`, 후보 0건**이었다. 검수된 실제 문서 gold는 0개이므로 discovery recall·구조화 정확도는 미측정이며, 채점기는 `inconclusive`, `pass:false`를 반환한다. 이 실행을 제품 품질 통과로 사용하지 않는다.

## 실제 관측

| 집합 | 질의 수 | 후보가 나온 질의 | 반환 후보 수 |
|---|---:|---:|---:|
| 중학교 과학 | 5 | 0 | 0 |
| 중학교 수학 | 5 | 0 | 0 |
| 중학교 국어 | 5 | 0 | 0 |
| 고등학교 과학 | 5 | 0 | 0 |
| 기타 | 10 | 0 | 0 |

추가 대조 질의 `광합성`은 `partial`로 후보 9개를 반환했다. 상세 경로 미검증·메타데이터 수·응답 크기 제한 경고가 있었다. `성취수준`, `성취기준`은 각각 후보 0건이었다. 따라서 검색 연결 전체가 실패한 상황과는 구분된다. 다만 반환된 9개가 실제 성취수준 문서인지는 검증하지 않았다. 복합 질의 처리, 공식 인덱스 수록 범위, 다른 공식 발견 경로 중 어느 것이 원인인지는 별도 확인이 필요하다.

기본 첫 페이지(최대 20개 후보), HWPX off인 평가 프로필에서 관측했다. 검색 범위의 미발견을 실제 자료 부재나 recall 0으로 일반화하지 않는다. 이번 실행에는 첨부 다운로드·실문서 구조화 채점·ChatGPT/Claude 호출이 없다.

## 구현과 검증

- 실제 MCP를 통한 발견·첨부 목록·문서 이어 읽기 수집기, 코퍼스/검토 양식, 독립 채점기를 추가했다. 사용법과 지표 정의는 [제품 eval 안내](../evals/achievement-product/README.md)에 있다.
- 승인된 gold에 대한 검색 recall@k, 레코드/필드 precision·recall, 성취수준 레코드 별도 지표, 원문 라벨·근거 정확도, 자동 첨부 선택·보류를 측정한다.
- 순서가 달라도 일대일 대응하며 중복 출력·누락·해시 변경·근거 행 변경을 검출한다. gold 미검토·분모 0·표본 부족은 합격으로 처리하지 않는다.
- 새 eval 테스트 **47/47**, 전체 계약·회귀 **279/279**, TypeScript 검사 통과.
- 전체 회귀 첫 실행에서 기존 `fault-worker.cjs`의 timeout 모드가 IPC listener 종료 후 바로 종료되는 결함을 발견했다. timeout 모드가 실제로 대기하도록 fixture만 수정한 뒤 회귀 검사를 통과했다. 생산 검색·파서 코드는 수정하지 않았다.
- 클라이언트 전체 흐름 12개는 수동 실행용 시나리오이며 모두 미실행이다.
