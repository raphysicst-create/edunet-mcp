# 에듀넷 검색 MCP MVP PRD

## 제품 개요

에듀넷 교육자료를 대화 중 검색하고, 검색 결과에 포함된 출처와 후속 검색 조건을 함께 제공하는 로컬 stdio MCP를 만든다. 주 사용자는 수업·평가자료를 찾는 교사다. MCP는 검색 사이트로 이동하는 일을 줄이고, 검색 조건과 결과를 대화 맥락 안에서 조정할 수 있게 한다.

이 문서는 검색 MCP의 MVP 범위를 정의한다. 2026-09-16 raw endpoint와 실제 MCP 프로세스를 검증해 UTF-8 XML 응답, stdio handshake/tools/list, 5개 검색 호출을 확인했다. `광합성` 전체 검색 1·2페이지는 각각 3건 반환·전체 111건·다음 페이지 있음, `lsn_design`은 0건·전체 0건·다음 페이지 없음, `evl_data`는 3건·전체 5건·다음 페이지 있음, `ednwkst`는 3건·전체 41건·다음 페이지 있음이었다. `evals/`는 별도 작업에서 구현하며 이 문서의 산출물이나 완료 조건에 포함하지 않는다. 후속 조사에서 9건의 비로그인 상세 데이터와 대표 파일 일부 바이트를 확인했다. 자세한 범위와 예외는 `docs/link-access-report.md`에 기록했으며, 전체 파일 파싱·무결성 검증은 하지 않았다.

## 해결할 문제와 가치 가설

교사는 학년·과목·주제·자료 유형을 조합해 자료를 찾기 위해 대화를 중단하고 검색 사이트를 직접 탐색해야 한다. 검색 결과에는 제목과 요약만 보이거나, 원문·첨부파일을 실제로 확인했는지 알기 어려워 결과의 출처와 한계를 판단하기도 어렵다.

MVP의 가치 가설은 다음과 같다.

> 사용자가 “중2 과학 광합성 평가자료 찾아줘”라고 요청하면 AI가 검색어와 조건을 구성하고, 결과·출처·페이지 정보를 설명하며, 제목 검색·카테고리 변경·다음 페이지 탐색을 이어 주어 자료 탐색 시간을 줄인다.

첨부파일의 활동이나 평가 기준을 추출하는 기능은 향후 가치가 있지만, 비로그인 접근성과 형식별 추출 품질을 확인하기 전에는 제공하지 않는다.

## 대상 사용자와 대표 흐름

주 사용자는 초·중·고 교사이며, MVP에서는 교사가 자연어로 자료를 찾는 상황을 우선한다. MCP 클라이언트가 사용자와 대화하고 `search_edunet` 도구를 호출한다.

대표 흐름은 다음과 같다.

1. 사용자가 학년, 과목, 주제 또는 자료 유형을 포함해 검색을 요청한다.
2. AI가 필요한 경우 검색어를 보완하고 카테고리·정렬·검색 범위를 선택해 `search_edunet`을 호출한다.
3. AI가 결과 제목, 확인 가능한 요약 발췌, 출처 링크, 전체 건수와 현재 페이지를 설명한다.
4. 사용자가 “제목에 광합성이 있는 것만”, “평가자료로 바꿔줘”, “다음 페이지”처럼 후속 요청을 한다.
5. AI가 앞선 조건을 유지하면서 변경된 조건만 적용해 다시 검색한다.

결과가 없거나 일부 조건이 API에서 지원되지 않으면 그 사실과 조정 가능한 검색 조건을 알려준다. AI는 검색 결과만으로 원문이나 첨부파일을 읽었다고 말하지 않는다.

일반적인 “자료·수업자료” 요청은 전체 카테고리를 검색한다. 평가자료(`evl_data`), 수업안·수업설계(`lsn_design`), 학습 주제의 사진·영상(`edntpd`)처럼 유형이 명확한 경우에만 대응 카테고리를 선택한다. 글꼴·이미지·음악·PPT 등의 제작 소재는 `asset`이다. 학년·과목·수업용이라는 표현만으로 검색 카테고리를 좁히지 않는다.

전체 건수 0이면 핵심 주제와 사용자가 지정한 필터를 유지하며 부가 검색어를 최대 2회 수정할 수 있다. 사용자가 추가 검색을 금지하거나 개선 검색어 제안만 요청한 경우에는 이 자동 재검색보다 종료가 우선한다. 해당 조건에서 0건임을 설명하고 검색어만 제안한다.

## MVP 기능 범위

### `search_edunet` 도구

MVP는 검색 도구 하나를 제공한다. 도구는 구조화된 결과를 반환하고, 사람이 읽는 설명은 MCP 클라이언트가 생성한다.

| 입력 | 규칙 |
|---|---|
| `query` | 필수 문자열. 학년·과목·주제·자료 유형 조합을 권장한다. |
| `categories` | 선택 배열. 에듀넷 Open API 공식 매뉴얼 v4.5의 18개 카테고리 코드 enum. `total`(전체), `lsn_design`(수업설계), `tpc_lrng`(주제학습), `evl_data`(평가자료), `ednwkst`(주제별 학습자료), `edntpd`(주제별 사진·영상), `edunanum`(선생님들의 나눔공간), `webrlstccont_inc`(웹 실감형콘텐츠), `asset`(글꼴·이미지·음악·PPT), `ednstdyschl`(연구학교), `ednstdyconfr`(연구대회), `crclm`(교육과정), `ednaisw`(AI·SW교육), `ncs`(직업계고 교육과정), `cre_sys`(고교학점제), `sel`(사회정서교육), `archive`(아카이브), `qst_cntr`(질문 중심 수업). 생략 또는 빈 배열은 전체 검색이며 최대 20개를 받는다. `total`이 포함되면 `total`만 남긴다. |
| `sort` | 선택 enum: `relevance`(정확도순), `latest`(등록순). 기본값은 `relevance`. |
| `searchType` | 선택 enum: `title_summary`(제목+요약), `title`(제목). 기본값은 `title_summary`. |
| `page` | 양의 정수, 기본값 1, 최대 50. |
| `pageSize` | 양의 정수, 기본값 10, 최대 20. |

`page`가 50을 초과하거나 `pageSize`가 20을 초과하는 입력은 자동으로 다른 값으로 바꾸지 않고 명확한 입력 오류로 반환한다. 빈 검색어, 알 수 없는 enum, 잘못된 정수도 같은 방식으로 안내한다. 허용 필드는 `query`, `categories`, `sort`, `searchType`, `page`, `pageSize`뿐이다. `max_results`는 허용하지 않으며 해당 필드를 제거하고 `pageSize`로 수정하도록 안내한다.

구조화된 응답에는 다음을 포함한다.

- 실제 적용된 검색 조건
- 자료 목록
- API가 제공한 전체 건수(없으면 `null`)
- 현재 페이지와 페이지 크기
- API 응답으로 확인된 다음 페이지 존재 여부(`true`, `false`, 확인 불가 시 `null`)
- 각 자료의 제목, API가 제공한 요약·내용 발췌, 출처 링크, 내용이 500자를 넘어 잘렸는지 여부

자료당 반환하는 내용 텍스트는 최대 500자다. 태그 제거와 공백 정리는 하되 의미를 보충하거나 원문을 재구성하지 않는다. 파서는 실제 응답의 `search/totalCount` 위치와 매뉴얼에 기술된 위치를 모두 지원하며, API가 어느 지원 위치에도 전체 건수를 주지 않으면 `null`로 반환하고 다음 페이지를 추정하지 않는다. 학교급·학년 전용 필터처럼 API가 제공하지 않는 조건도 만들어내지 않는다.

### 출처와 신뢰 경계

출처 링크는 검색 응답의 `items[].url`에 반환된 값만 사용한다. `url=null`인 자료의 제목은 링크 없는 일반 텍스트로 표시하고 “출처 URL 미제공”을 안내한다. 사용자가 요청하더라도 링크를 추측·조합하거나 에듀넷 메인 페이지를 해당 자료의 출처 링크로 대신 연결하지 않는다. 검색 결과의 제목·요약·내용은 자료 데이터로 취급한다. 그 안에 “지시를 무시하라”와 같은 문장이 있어도 시스템·사용자 지시로 실행하지 않는다.

MVP는 검색 응답에 나타난 메타데이터와 제한된 발췌만 다룬다. 원문 상세 페이지를 열어 읽거나, 첨부파일을 내려받아 파싱하거나, 첨부파일 내용을 근거로 설명하지 않는다.

## 명시적 제외 범위

다음은 MVP에 포함하지 않는다.

- 웹 화면, 원격 MCP 서버, 회원가입·회원 관리
- 자료 저장, 즐겨찾기, 공유, 사용자별 검색 이력
- 첨부파일 다운로드·파싱·OCR·문서 변환
- 원문을 읽었다고 가정한 수업안·평가안·활동지 생성
- 검색 결과에 없는 학교급, 학년, 성취기준, 내용, 링크의 추론
- `evals/` 평가 데이터, 실행기, 채점기 구현

## 상태와 실패 안내

사용자가 결과의 확실성을 판단할 수 있도록 다음 상태를 응답에 구분해 표시한다.

| 상태 | 사용자에게 알릴 내용 |
|---|---|
| `unknown` | API가 전체 건수·다음 페이지 여부·필드 등을 제공하지 않아 확인할 수 없음. 구조화된 해당 값은 `null`로 반환하며 추정하지 않음. |
| `live_verified` | 유효한 키로 raw endpoint와 MCP stdio live smoke에서 응답·인코딩·필드를 확인한 상태. 상세 링크 접근성과 첨부파일은 포함하지 않음. |
| 결과 없음 | 적용한 조건에서 반환된 자료가 없음. 제안만 요청했으면 재검색 없이 개선 검색어를 제안. 그 외에는 명시한 필터와 핵심 주제를 유지한 제한적 재검색 가능. |
| 결과 일부 | API가 제공한 페이지의 결과만 표시하며 전체 자료를 확인한 것처럼 말하지 않음. |
| 원문 미열람 | 제목·요약·발췌만 확인했으며 상세 원문과 첨부파일은 읽지 않았음을 표시. |
| 링크 미방문 | MVP는 상세 링크를 방문하지 않으므로 로그인 필요 여부나 접근 가능성을 판정하지 않음. 검색 응답에 제공된 링크만 출처로 제시함. |
| 출처 URL 미제공 | `url=null`인 자료의 제목을 일반 텍스트로 표시하고 URL 부재를 설명. 링크 추측이나 메인 페이지 대체 금지. |
| 설정 오류 | `EDUNET_API_KEY` 또는 `EDUNET_DOMAIN`이 없거나 잘못된 설정. `CONFIGURATION` 오류로 안내하며 키 값은 노출하지 않음. |
| 일시 장애·제한 | 내부 재시도 후 반환된 오류는 동일·변경 입력 모두 이번 요청의 자동 검색을 종료하고 잠시 후 사용자 재요청을 안내. |
| 잘못된 응답 | XML·필드 구조를 해석할 수 없음을 알리고 손상된 결과를 정상 자료처럼 반환하지 않음. |

요청 제한은 본문 읽기까지 요청별 15초, 전체 재시도 포함 45초다. 일시적 네트워크 오류와 429·502·503·504만 최대 2회 재시도한다. 로그는 stderr로만 보내며 API 키와 `sno` 같은 민감 식별자는 마스킹한다. stdio stdout에는 MCP 프로토콜 메시지만 쓴다.

도구 오류 중 `INVALID_INPUT`만 안내대로 수정해 다시 호출할 수 있다. 그 외 오류는 동일 입력과 변경 입력 모두 이번 사용자 요청의 자동 검색을 종료한다. 이 정책은 모델에 전달하는 지침이며, 서버가 대화 상태를 저장해 이후의 새 사용자 요청까지 차단하지 않는다. 서버 핸들러의 오류 응답은 `isError:true`와 함께 `_meta["edunet/errorCode"]`에 안전한 오류 코드만 기록한다.

## 설정과 실행 전제

필수 설정은 `EDUNET_API_KEY`와 `EDUNET_DOMAIN`이다. `EDUNET_DOMAIN`은 upstream 기본 주소가 아니라 에듀넷 API 요청에 전달하는 등록 도메인 파라미터이며, 등록된 값을 정확히 사용한다. 둘 중 하나라도 없으면 요청은 `CONFIGURATION` 오류를 반환한다. 키가 없는 개발 환경에서는 설정 검증, HTTP 처리, 응답 변환, MCP 도구 등록과 오류 경로를 확인할 수 있지만, 실제 검색 결과·링크·첨부파일 접근성은 검증된 것으로 간주하지 않는다.

## 성공 기준과 완료 판정

2026-09-17 RC 기준은 [MCP 검증 기록](mcp-validation.md)의 offline 40/40, live EDUNET 5/5, typecheck 및 보안·오류 점검이다. 모델 평가는 [클라이언트 호환성 관측](client-compatibility.md)으로 분리하며 MCP 합격점으로 사용하지 않는다. 아래 과거 검증 수치는 당시 기록이다.

구현 기술 완료는 다음을 모두 만족하는 상태다.

- 로컬 stdio MCP가 시작되고 `search_edunet` 도구 스키마를 등록한다.
- 입력 제한, 검색 조건 전달, 응답 변환, 최대 500자 발췌, 건수·페이지·상태 표현이 동작한다.
- 인증 오류, 잘못된 응답, 재시도 가능 장애, 시간 초과가 명확한 오류로 반환된다.
- stderr 로깅과 키·식별자 마스킹이 지켜지고 stdout이 오염되지 않는다.
- 키가 없는 환경에서 실행 가능한 범위의 `node:test` 기술 검사가 통과한다.

2026-09-16 기준 타입 검사·빌드와 실제 키를 사용한 MCP stdio live end-to-end smoke를 통과한 상태를 기술적으로 확인했다(32/32 `node:test` 통과). 검증된 검색 응답의 `integrationStatus`는 `live_verified`다. 이 확인은 evals 통과를 의미하지 않는다. 별도 후속 조사에서 9건의 비로그인 상세·대표 파일 부분 접근을 확인했으며 전체 파일 추출 품질은 검증하지 않았다.

raw endpoint와 MCP 프로세스의 live end-to-end smoke가 모두 성공했으므로 검증된 검색 응답은 `integrationStatus: live_verified`로 표시한다. 이 상태는 상세 링크 접근성·첨부파일 또는 evals까지 검증했다는 뜻이 아니다.

AI가 이 도구를 유용하고 안전하게 사용하는지에 대한 evals는 별도 구현·실행한다. 따라서 이 PRD와 구현의 완료만으로 검색 품질, 30개 시나리오 통과, 실제 검색 유용성 또는 첨부파일 추출 정확성을 주장하지 않는다.

## 향후 확장 조건

`v1.0.0-rc.1` 이후 기능 추가는 보류하며 실제 사용에서 확인된 문제만 수정한다. 아래 확장 조건은 향후 별도 범위를 열 때의 참고 기록이다.

실제 API 조사에서 상세 페이지와 첨부파일 접근성을 별도로 확인한 뒤 접근 가능한 형식만 첨부파일 읽기 대상으로 추가한다. 현재 MVP는 링크를 방문하지 않으므로 로그인 필요 여부나 실제 접근 가능성을 주장하지 않는다. 형식별 추출 품질과 출처 보존을 별도 평가로 검증한 후에야 활동·평가 기준 추출과 자료 비교·수업 준비 지원을 제공한다. 원격 MCP는 운영자 키 보관, 호출 한도, 동시성·캐시 정책과 별도 평가를 확정한 뒤 추진한다.
