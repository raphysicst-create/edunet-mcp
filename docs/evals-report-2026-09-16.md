# Evals 실행 보고서 — 2026-09-16

edunet-mcp의 계약 평가와 실제 검색 수집을 실행했다. **릴리스 통과 상태가 아니다.**

최근 구독 경로 후속 작업: 사용자가 선택한 실행 경로는 API가 아닌 Terra 구독이다. [분리 환경 재검사](subscription-isolation-2026-09-16.md)에서 실제 로컬 CLI 요청의 추가 도구와 기본 지침을 확인했다. 현재 차단 요인은 구독 환경 격리 미완료이며 API 크레딧과 무관하다. 새 구독 모델 호출 0건, 최종 계약 88/88 통과. 아래 API 연결 실패는 이전 작업의 이력으로 보존한다.

## 후속 작업 — 결과 보존·판정 분리·재평가 v3

- 일반 평가·검토 양식·채점 JSON을 배타적으로 생성한다. 같은 실행에서 새로 연 파일 핸들로만 진행 저장이 가능하다. 재채점·재집계·검토 패킷도 기존 파일을 거절한다. 기존 `evals/results/` 보고서와 사람 검토 기록은 수정·삭제하지 않았다.
- 실행기/어댑터/fixture/채점기/제품 전체 src·실행 dist/도구 설명·공통 안내/의존성 파일의 개별·집계 해시를 기록한다. 채점 출력은 원본·검토 해시와 실제 채점 구현 provenance를 별도로 남긴다.
- 제품 위반, 환경 오류, 판정 보류를 분리했다. 동시 발생 증거는 모두 보존한다. 분류별 비율에 분자·분모를 표시한다. 환경 오류·보류는 성공도 제품 실패율의 실패도 아니며, 한 건이라도 릴리스를 차단한다. 릴리스 성공률은 고정 90회 기준이며 81회 이상·중대 위반 0건·전체 사람 검토·유효한 환경/버전 증거 조건을 유지한다.
- 기존 ID를 사용하는 connection(1건), representative(8개×3회), full(30개×3회) 단계를 추가했다. 부분 실행은 전체 릴리스 평가로 사용할 수 없다. 비교기는 모델·설정·실행기·fixture·채점기·환경·버전 증거 등을 확인한다.
- 프로젝트/상위 폴더의 Git 이력이 없고 프로젝트 및 `.scratch`에 검증 가능한 이전 제품 전체 소스가 없었다. 이전 구독 실행기 사본만으로 이전 제품을 복원하지 않았다. 현재 제품을 새 기준선으로 정하고 [88개 파일 스냅샷](../.scratch/eval-v3-source-snapshot/snapshot.json)을 보존했다. 기존 구독 90회와 새 결과는 [비교 불가](../.scratch/eval-v3-historical-comparison.json)로 기록했다.

검증: TypeScript 타입 검사·빌드 통과. [최종 계약 검사](../.scratch/eval-v3-contract-verified.json) **85/85 통과**, 전체 고정 응답 smoke **30/30**, 대표 고정 응답 smoke **24/24** 자동 검사 통과. smoke는 모델 성능이 아니다. API 환경 preflight는 search_edunet 한 개와 공통 지침만 노출됨을 확인했다. 구독 격리는 여전히 미검증이며 계약 테스트에서도 통제 평가 승격을 차단한다.

[검증 요약](../.scratch/eval-v3-validation-summary.json), [전체 smoke](../.scratch/eval-v3-verified-smoke.json), [대표 smoke](../.scratch/eval-v3-verified-representative.json), [환경 preflight](../.scratch/eval-v3-verified-preflight.json). 스냅샷의 구현 해시 일치 확인, 신규 JSON 산출물 24개의 설정된 실제 키 검사 검출 0건.

Terra 연결 점검: 샌드박스 내 최초 시도는 HTTP 응답 증거 없이 실패했다. 외부 네트워크 권한으로 한 번 재확인한 [연결 점검](../.scratch/eval-v3-terra-network-connection.json)은 **HTTP 429 / credit_balance_exhausted**였다. 모델 응답 0건, 대표 성능 평가 0/24회, 전체 성능 평가 0/90회. 할당량 거절 후 반복 호출하지 않았고 구독 경로로 우회하지 않았다. 사람 검토는 모두 미완료이며 [새 검토 양식](../.scratch/eval-v3-terra-network-connection-review.json)은 비어 있다.

[별도 채점 결과](../.scratch/eval-v3-terra-final-grade.json)는 제품 위반 0건, 환경 오류 1건, 보류 1건, 성공 0/90이다. 제품 실패율은 유효한 판정 대상이 0건이므로 null이다. 연결 시도 후 채점 구현이 갱신되어 `scorer_implementation_changed`도 정직하게 남긴다. 실패한 연결 시도를 새 구현으로 실행한 것처럼 원본 provenance를 바꾸지 않았다. 환경 오류 1/1과 보류 1/1은 같은 기록에 중복 해당한다.

재개 차단 요인은 API 크레딧과 미확인 모델 버전이다. 크레딧 해결 후 [실행 안내](../evals/README.md)의 새 경로로 연결 점검 → 대표 24회 및 검토·수정 → 전체 90회 → 사람 검토를 진행한다. 첨부파일 기능과 사용자 전역 설정은 변경하지 않았다.

## 사용자 영향과 검색어 안내 개선안

현재 안내대로 학년·과목·주제 전체를 하나의 검색어로 넣으면 교사가 자료가 없다고 판단하고 탐색을 중단할 수 있다. 검색 0건 시 학년·과목 맥락은 대화에 유지하되 주제 검색으로 범위를 넓히고, 카테고리가 너무 좁으면 전체 검색을 제안해야 한다. 학년·과목·자료 유형 적합성은 결과의 메타데이터로 확인하며 미확인 사항을 숨기지 않는다.

개선 안내 예: “0건이면 핵심 주제로 검색어를 줄여 다시 찾아보세요. 선택 카테고리에 자료가 없으면 전체 검색으로 넓힐 수 있습니다. 검색 결과의 학년·과목 적합성은 별도로 확인해야 합니다.”

위 안내에 따른 재검색에서 6개 과제가 반환 자료를 얻었다. 그러나 분수의 상위 결과에 동음이의어인 분수대가 섞이고, 환경 검색은 영어 토론 자료라는 조건을 보장하지 않는다. 결과 회복과 검색 유용성은 구별해야 한다. 이 실행에서는 서버 검색 정책·도구 설명·평가 케이스를 변경하지 않았으며 안내 개선안의 제품 적용은 별도 작업이다.
