# 클라이언트 호환성 관측

이 문서는 클라이언트 모델이 MCP를 어떻게 사용하는지에 관한 별도 참고다. **Terra·Sonnet 점수를 MCP 합격점으로 사용하지 않는다.** MCP의 입력·응답·통신·오류 처리 검증은 [MCP 검증 기록](mcp-validation.md)에 있다.

## 수행한 관측

| 대상 | 수행 상태 | 관측된 행동과 해석 |
|---|---|---|
| Terra | 평가 수행, 두 번째 시범 90개 세션·최종 응답 확보 | 오류 이후 재호출, 조건 누락, 범위 밖 페이지 입력 등이 관측됨. [원본 보고서](terra-subscription-pilot-second-90-2026-09-17.md) |
| Claude Sonnet | 평가 수행, 보완 후 최종 표본 90개 세션 | 최초 검색 조건 누락, 카테고리 분할 검색, 출처 관련 자동 경고 등이 관측됨. 일부는 fixture·채점 설계와 의미 판단 검토가 필요함. [보완 보고서](claude-sonnet-pilot-corrected-90-2026-09-17.md) |

모델별 행동 차이가 존재한다. 환경 격리·정확한 실행 모델 버전·사람 검토의 제한이 있으므로 자동 clean 수치를 품질 보증이나 모델 간 우열로 해석하지 않는다. 과거 점수와 원본 결과는 그대로 보존하며 이 RC에서 모델 평가를 다시 실행하지 않았다.

## 사용자에게 미치는 영향

- 서버가 입력을 거부해도 모델이 불필요한 재호출을 시도할 수 있다.
- 모델이 검색어에서 학년·과목을 누락하거나 요청과 다른 카테고리를 선택할 수 있다. 반환된 검색 조건을 확인한다.
- MCP는 없는 출처 URL을 만들지 않는다. 최종 답변의 링크 생성·원문 열람 주장까지 서버가 강제할 수는 없다.

실제 Codex 대화 연결 이력은 [연결 보고서](client-connection-report.md)에 있다. 프로토콜 연결 확인과 모델 행동 평가는 서로 다른 증거다. 평가 실행 방법과 과거 판정 필드 해석은 [evals 안내](../evals/README.md)를 참고한다.
