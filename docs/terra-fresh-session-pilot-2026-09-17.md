사용자 요청에 따라 Codex 앱에서 `gpt-5.6-terra`를 지정한 새 프로젝트 세션을 만들었다. 기존 대화를 이어 쓰지 않고 검색 과제 1건과 시범 제한만 전달했다. 세션 제목은 `Terra 새 세션 에듀넷 검색 시범`, ID는 `01a0aca4-e6df-7400-a17a-6878e041453c`이다.

약 30초 안에 실제 EDUNET MCP 검색 2회와 최종 답변을 완료했다. 호출 기록에서 다음 입력을 확인했다.

| 호출 | 검색어 | 카테고리 | 페이지 | 페이지 크기 |
|---|---|---|---:|---:|
| 1 | 중2 과학 광합성 | evl_data | 1 | 10 |
| 2 | 광합성 | evl_data | 1 | 10 |

두 호출 모두 relevance 정렬과 title_summary 검색을 유지했다. 새 세션의 최종 답변은 첫 검색 0건, 검색어 완화 후 5건이라고 보고하고 자료 링크 5개를 제시했다. 학년 적합성은 별도 확인이 필요하며 원문·첨부파일은 읽지 않았다고 밝혔다. 세션 조회 기록에는 검색 외 행동 도구 호출이 보이지 않았다.

이는 **새 구독 세션에서 검색이 실행되는지 확인한 사용성 시범**이다. `codex_usage_unverified`로 기록하며 통제 평가나 릴리스 점수로 쓰지 않는다. 실검색 백엔드를 사용했으므로 고정 fixture 30개 평가와도 다르다. API 평가기는 호출하지 않았다.

세션 조회 도구가 MCP 응답 본문을 반환하지 않아 0건·5건과 링크의 출처 일치는 최종 답변의 보고 내용이며 독립 검증하지 못했다. 전체 도구·지침 격리, fixture 읽기 차단, 실제 응답 모델 스냅샷과 토큰 사용량은 미확인이다. 사람 검토 필드는 비워 두었다.
